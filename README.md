## 구현 항목 체크(기능 체크표)

| 요구사항 | 상태 | 한 줄 메모 |
|---|---|---|
| 1 렌더링 | 구현함 | 고유 제목 10편을 JS로 생성하고 data-type, 평점 8 이상 hot, 박스오피스 순위를 적용함. |
| 2 검색 | 구현함 | input 이벤트로 제목을 검색하며 앞뒤 공백과 대소문자를 무시함. |
| 3 정렬 3종 | 구현함 | 평점·연도 내림차순, 제목 오름차순으로 정렬함. |
| 4 보기 필터와 getView | 구현함 | 검색 → 보기 필터 → 정렬을 getView 하나에서 처리함. |
| 5 찜과 저장 | 구현함 | 보드 클릭 리스너 하나에서 토글하고 제목 배열을 localStorage에 저장함. |
| 6 빈 결과 | 구현함 | 0건일 때 is-empty 클래스로 안내 문구를 표시함. |
| 7 상세 대화상자 | 구현함 | 포스터 w500, 제목, 개봉일, 평점, 줄거리를 채워 열고 닫기 버튼을 연결함. 실제 브라우저의 Esc 동작은 확인 전임. |
| 8 인라인 이벤트 속성 없음, 콘솔 오류 0 | 일부 | 인라인 이벤트 없이 렌더 함수 밖에서 리스너를 한 번씩 등록함. 실제 브라우저 콘솔 검사는 남아 있음. |

## 어려웠던 점 3가지와 해결

1. 검색, 보기, 정렬이 서로 풀리는 문제: getView에서 세 조건을 순서대로 처리하고 모든 변경 이벤트에서 refresh를 호출했습니다.
2. 카드를 다시 그리면 찜 표시가 사라지는 문제: 찜한 제목을 배열에 저장하고 renderCards에서 liked.includes로 표시를 복원했습니다.
3. 찜 버튼을 눌렀을 때 상세도 열리는 문제: 찜 처리 뒤 return하여 상세 열기로 이어지지 않도록 했습니다.
